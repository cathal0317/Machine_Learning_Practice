# 2.2 Constrained optimization

## Conceptual overview
This section introduces optimization where the solution must belong to a restricted 'feasibility set' defined by equality and inequality constraints. It establishes the standard notation $(P)$ for such problems and defines key terms like linear programming and convex sets in this context.

## Why it matters
Real-world problems, such as SVMs, require optimization under constraints (like margins or budget limits).

## Active recall
> [!question]- What defines the feasibility set $\mathcal{F}$ in standard form?
> It is the set of all $w$ satisfying $f_i(w) \leq 0$ for all $i$ and $Aw = b$.

## Narrative flow
The subsection starts by defining the feasibility set and identifying convex problems. It then launches a deep dive into Duality (Subsection 2.2.1), covering the Lagrange dual, weak/strong duality, and finishing with the Karush-Kuhn-Tucker (KKT) conditions.
