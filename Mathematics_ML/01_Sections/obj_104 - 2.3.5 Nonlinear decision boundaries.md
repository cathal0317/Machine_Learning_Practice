# 2.3.5 Nonlinear decision boundaries

## Conceptual overview
This subsection introduces the idea of 'lifting' data into a higher-dimensional feature space $\mathbb{R}^d$ using a map $\Phi$. If data is not linearly separable in the original space, it may become separable in this transformed space, allowing for complex decision boundaries like polynomials.

## Why it matters
This is the conceptual foundation for the kernel trick, one of the most important developments in machine learning.

## Active recall
> [!question]- What is the purpose of the feature map $\Phi(x)$?
> The feature map transforms data into a high-dimensional space where a linear separator may exist for data that is nonlinearly separable in the original space.

## Narrative flow
The subsection motivates the need for nonlinear boundaries, defines the feature map approach, and provides an example using quadratic polynomials.
