# 3.4 Common neural network architectures

## Conceptual overview
Surveys architectures beyond the simple MLP, focusing on those designed for specific data types like images (CNNs) and sequences (Transformers).

## Why it matters
Real-world machine learning success relies on choosing the right inductive bias for the data, which these architectures provide.

## Active recall
> [!question]- Which architecture family is particularly important for Natural Language Processing (NLP)?
> Transformers, introduced in 2017.

## Narrative flow
Iterates through the two most impactful architecture families: CNNs for vision/spatial data and Transformers for sequence data.
