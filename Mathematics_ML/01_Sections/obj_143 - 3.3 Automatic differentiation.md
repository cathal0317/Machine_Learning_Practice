# 3.3 Automatic differentiation

## Conceptual overview
Explains how to efficiently compute gradients in a recursive manner using computational graphs. It details the mechanisms of forward mode (tracking derivatives alongside values) and reverse mode (propagating gradients backward).

## Why it matters
Efficient gradient computation is the central bottleneck of neural network optimization; automatic differentiation makes deep learning practical.

## Active recall
> [!question]- What is 'back-propagation' in the context of automatic differentiation?
> It is a clever implementation of the chain rule and a special case of reverse mode automatic differentiation applied to neural networks.

## Narrative flow
Motivates the need for recursive gradient computation, introduces computational graphs, explores forward mode (via dual numbers), and then explains reverse mode and backpropagation.
