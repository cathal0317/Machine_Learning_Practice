# 3.3.3 Forward mode

## Conceptual overview
Describes an algorithm that propagates derivative values $\dot{z}_k = \partial z_k / \partial x_j$ from the inputs through the graph. It uses the chain rule to recursively compute the derivative of each node with respect to a single chosen input.

## Why it matters
It is an efficient way to compute the Jacobian-vector product in one forward pass.

## Active recall
> [!question]- How are initial derivative values $\dot{z}_{-i}$ initialized in forward mode to compute $\partial f / \partial x_j$?
> They are initialized as $1$ if $i = j$ and $0$ otherwise.

## Narrative flow
Develops the recursive chain rule steps for forward differentiation and then introduces dual numbers as an elegant implementation technique.
