# 1.5.1 Decomposition of excess risk

## Conceptual overview
Excess risk is decomposed into estimation error (the gap between ERM and the best function in $\mathcal{H}$) and approximation error (the gap between the best function in $\mathcal{H}$ and the Bayes classifier). This is a formalization of the variance-bias trade-off in the risk domain.

## Why it matters
This decomposition dictates model selection: a large class $\mathcal{H}$ reduces approximation error but increases estimation error (overfitting), while a small class does the opposite.

## Active recall
> [!question]- State the excess risk decomposition formula.
> $R(\hat{h}) - R(h^*) = (R(\hat{h}) - \inf_{h \in \mathcal{H}} R(h)) + (\inf_{h \in \mathcal{H}} R(h) - R(h^*))$, representing estimation and approximation error respectively.

## Narrative flow
The subsection defines the decomposition algebraically and then discusses the approximation error component specifically, including how Lipschitz continuity of the loss function can be used to bound it.
