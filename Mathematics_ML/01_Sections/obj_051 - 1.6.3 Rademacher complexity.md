# 1.6.3 Rademacher complexity

## Conceptual overview
Rademacher complexity measures how well a function class can correlate with random noise (Rademacher variables). It provides a way to quantify the complexity of infinite classes without relying on simple counting.

## Why it matters
It is the standard tool in statistical learning theory for proving generalization bounds for modern, continuous parameter models like neural networks.

## Active recall
> [!question]- What does Rademacher complexity intuitively measure?
> It measures a function class's ability to 'fit' random noise; if it can fit noise well, it is highly complex and prone to overfitting.

## Narrative flow
The section defines Rademacher complexity (Definition 3), provides simple examples (Example 8), and then states two fundamental theorems (Theorem 8 and 9) that link this complexity directly to expected excess risk. It concludes with an important example for linear models (Example 9).
