# 1.2.1 Conditional expectation

## Conceptual overview
This subsection serves as a mathematical review of conditional expectation $g(w) = E(Z | W = w)$. It defines it via the conditional probability density function $f_{z|w}$ and lists key properties such as independence, the tower property, and conditional Jensen's inequality. These properties are essential for deriving the Bayes classifier and analyzing its risk.

## Why it matters
Conditional expectation is the 'machinery' used to define the regression function and to prove that the Bayes classifier is optimal.

## Active recall
> [!question]- What is the 'Tower property' of conditional expectation?
> It states that $\mathbb{E}(\mathbb{E}(Z \mid W) \mid f(W)) = \mathbb{E}(Z \mid f(W))$. A simpler version is $\mathbb{E}(\mathbb{E}(Z \mid W)) = \mathbb{E}(Z)$.

> [!question]- State the Conditional Jensen's inequality.
> For a convex function $f$, $\mathbb{E}(f(Z) \mid W) \geq f(\mathbb{E}(Z \mid W))$.

## Narrative flow
Defines the conditional PDF, defines the conditional expectation as an integral, and then lists four crucial properties (Independence, Tower, 'Taking out what is known', and Least Squares Optimality).
