# 3.3.4 Reverse mode

## Conceptual overview
Introduces the algorithm that starts from the output node and works backwards to the inputs to compute partial derivatives. It defines a value $\dot{z}_k = \partial f / \partial z_k$ for every node and uses a recurrence relation based on child nodes.

## Why it matters
Reverse mode is significantly more efficient than forward mode for functions with many inputs and few outputs, which is the exact structure of neural network training.

## Active recall
> [!question]- What value is $\dot{z}_{n+1}$ initialized to in reverse mode?
> It is initialized to 1, representing $\partial f / \partial z_{n+1}$ where $f = z_{n+1}$.

> [!question]- State the recursive formula for $\dot{z}_k$ in reverse mode.
> $\dot{z}_k = \sum_{m \in \text{Child}(k)} \dot{z}_m \frac{\partial z_m}{\partial z_k}$.

## Narrative flow
Defines the backward traversal process, establishes the notation $\dot{z}_k$, provides the recursive formula, and then illustrates it with an example.
