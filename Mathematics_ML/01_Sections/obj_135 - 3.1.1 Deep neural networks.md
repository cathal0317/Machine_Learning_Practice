# 3.1.1 Deep neural networks

## Conceptual overview
Deep neural networks are defined as the composition of multiple layers of perceptrons, where the output of one layer serves as the input to the next. This layered structure allows the network to learn increasingly abstract representations of the input data.

## Why it matters
Depth is the defining characteristic of modern neural networks, enabling them to solve highly complex tasks that shallow models cannot.

## Active recall
> [!question]- How is a deep neural network defined recursively?
> It is defined by $F^1(x) = \sigma(W_1x + b^1)$ and $F^{k+1}(x) = \sigma(W_{k+1}F^k(x) + b^{k+1})$ for $k = 1, ..., L-1$.

> [!question]- What is the 'format' of a deep neural network?
> The format is a vector $d = (d_1, ..., d_L)$ specifying the number of neurons in each of the $L$ layers.

## Narrative flow
The subsection defines the recursive layer structure and then introduces the hypothesis space $\mathcal{H}$ for deep models, noting how the output layer is typically adapted for classification or regression.
