# 3.1 Multilayer perceptrons

## Conceptual overview
This subsection introduces the multilayer perceptron (MLP) as a powerful class of nonlinear models. It defines how neurons are formed by applying nonlinear activation functions to linear combinations of inputs, and how these neurons can be composed to form deep networks.

## Why it matters
MLPs are the foundation of deep learning, representing the transition from simple linear classifiers to flexible function approximators.

## Active recall
> [!question]- How is a single-hidden-layer neural network mathematically defined?
> It is defined as a function $h_{w,a,b}(x) = \sum_{i=1}^q a_i \sigma(x^\top w_i + b_i)$, where $\sigma$ is a nonlinear activation function.

> [!question]- What are some popular choices for the activation function $\sigma$?
> Common choices include the sigmoid function $\sigma(r) = e^r / (1 + e^r)$ and the Rectified Linear Unit (ReLU) $\rho(r) = \max(r, 0)$.

## Narrative flow
The subsection starts with the definition of a single perceptron, moves to the matrix notation for a full layer, discusses the need for nonlinearity (expressiveness), and concludes with the introduction of deep networks formed by stacking multiple layers.
