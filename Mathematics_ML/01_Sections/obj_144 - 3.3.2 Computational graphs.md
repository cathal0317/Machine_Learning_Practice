# 3.3.2 Computational graphs

## Conceptual overview
Formalizes functions as sequences of intermediate operations represented by nodes in a DAG. This structure allows the systematic application of the chain rule for both forward and reverse differentiation.

## Why it matters
Computational graphs are the fundamental abstraction used by modern deep learning libraries like PyTorch and TensorFlow.

## Active recall
> [!question]- What does an edge from node $z_k$ to node $z_l$ indicate in a computational graph?
> It indicates that the intermediate value $z_k$ is used as an input to compute the function $f_l$ associated with node $z_l$.

## Narrative flow
Defines intermediate values $z_k$ and nodes in a graph, then illustrates this with a concrete example of a function $f(x,y) = xy + \sin(x)$.
