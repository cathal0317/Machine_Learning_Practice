# 1.1 Classification and regression

## Conceptual overview
This subsection introduces the core framework of supervised learning, where a pair of random variables $(X, Y)$ with a joint distribution $P_0$ is observed. It defines the goal of learning a hypothesis $h$ that accurately predicts $Y$ from $X$ by minimizing an associated risk function. It contrasts discrete classification with continuous regression, providing the basic vocabulary for the entire module.

## Why it matters
It establishes the basic 'statistical learning' setup used in nearly every subsequent theorem and algorithm in the module.

## Narrative flow
Starts with the motivation for learning from features $X$, defines the types of tasks (regression vs. classification), introduces the concept of a loss function to measure error, and concludes with the aggregate measure of error: Risk.
