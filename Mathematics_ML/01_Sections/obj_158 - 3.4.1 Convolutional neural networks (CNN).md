# 3.4.1 Convolutional neural networks (CNN)

## Conceptual overview
Introduces CNNs as specialized architectures that use convolution operators to ensure translation invariance and parameter efficiency. It covers key components including convolutional filters, channels, max-pooling for subsampling, and skip connections for deep optimization.

## Why it matters
CNNs revolutionized computer vision by efficiently exploiting the spatial structure of images.

## Active recall
> [!question]- Why do CNNs have fewer parameters than fully connected networks for large images?
> Because they use weight sharing: the same small convolutional filter is applied to every spatial position in the input, whereas a fully connected layer would require separate weights for every pixel interaction.

> [!question]- How is translation invariance achieved in a CNN?
> By using convolution operators, which are the only linear operators that are invariant to translations.

## Narrative flow
Starts by defining CNNs as feedforward networks with convolution operators, explains the channel and parameter logic, and then introduces supporting techniques like max-pooling and residual connections.
