# 3.2 Cross-entropy loss

## Conceptual overview
Derives the standard loss function for classification by minimizing the KL divergence between an observed data distribution and a parameterized model. It shows how multi-class and binary classification relate to this framework.

## Why it matters
Cross-entropy is the standard loss function used for classification tasks in machine learning due to its information-theoretic foundations and favorable optimization properties.

## Active recall
> [!question]- How is the Kullback-Leibler divergence defined for discrete distributions $P$ and $Q$?
> $KL(P|Q) = \sum_{\omega \in \Omega} \log (P(\omega)/Q(\omega)) P(\omega)$.

> [!question]- What is the relationship between minimizing KL divergence and Maximum Likelihood Estimation (MLE)?
> Finding $\theta$ to minimize $KL(P|Q_\theta)$ is equivalent to maximizing the expected log-likelihood $\mathbb{E}_P(\log(Q_\theta))$.

## Narrative flow
Starts with the definition of KL divergence, establishes the link to MLE, and then provides explicit cross-entropy loss formulas for K-class classification (using softmax) and binary classification (using logistic).
